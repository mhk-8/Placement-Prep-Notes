# C++ for Interviews

> Folder: `03_Languages/CPP`

## Why this matters
Fastest execution, richest competitive library. Best default for OAs with tight time limits.

## Must-know checklist
- [ ] STL containers: vector, string, map/unordered_map, set/multiset, deque, priority_queue
- [ ] STL algorithms: sort, lower_bound, next_permutation, accumulate, __gcd
- [ ] Iterators, references, pointers; auto and range-for
- [ ] Custom comparators (lambda, struct, operator<)
- [ ] Fast I/O: ios_base::sync_with_stdio(false), cin.tie(nullptr)
- [ ] long long, overflow, INT_MAX; #define and constants
- [ ] Smart pointers, RAII, move semantics (for OOP rounds)

## Online-assessment angle
Use `vector<vector<int>>` over raw arrays; avoid `endl` in loops (it flushes).

## Interview angle
Expect questions on virtual functions, vtables, memory layout, and why you'd use unique_ptr.
