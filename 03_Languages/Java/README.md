# Java for Interviews

> Folder: `03_Languages/Java`

## Why this matters
Standard at many MNCs; strong typing catches bugs that Python hides.

## Must-know checklist
- [ ] Collections: ArrayList, HashMap, TreeMap, PriorityQueue, ArrayDeque
- [ ] Arrays and Collections utility methods; Comparator/Comparable
- [ ] StringBuilder vs String concatenation
- [ ] Autoboxing pitfalls; Integer caching (-128..127)
- [ ] BufferedReader vs Scanner for fast input
- [ ] Streams API basics
- [ ] JVM: heap vs stack, GC, class loading
- [ ] equals/hashCode contract

## Online-assessment angle
Use BufferedReader + StringBuilder for large I/O; Scanner will TLE.

## Interview angle
equals/hashCode, immutability of String, and GC are standard Java interview questions.
