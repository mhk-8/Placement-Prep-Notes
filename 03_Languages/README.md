# 03 — Languages & Libraries

> Folder: `03_Languages`

## Why this matters
Fluency is a time multiplier. In a 90-minute OA, fumbling with syntax or the standard library costs you a whole problem.

## Must-know checklist
- [ ] Pick ONE primary language for OAs and be fluent; keep a second for readability
- [ ] Know the standard library data structures and their complexities
- [ ] Fast I/O for large inputs
- [ ] Language-specific traps: integer overflow, recursion limits, mutable defaults
- [ ] Be able to write 20 lines without a compile error on the first try

## Online-assessment angle
Type speed and library recall matter as much as algorithmic skill here.

## Interview angle
You may be asked why you chose this language, and about its memory model or GC.
