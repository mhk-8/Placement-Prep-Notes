# SQL

> Folder: `03_Languages/SQL`

## Why this matters
A separate OA section at many data-oriented companies, and used daily in data/ML roles.

## Must-know checklist
- [ ] SELECT execution order (FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY→LIMIT)
- [ ] All join types + self joins + anti-joins
- [ ] Aggregations, GROUP BY, HAVING
- [ ] Window functions: ROW_NUMBER, RANK, DENSE_RANK, LAG/LEAD, running totals
- [ ] CTEs and recursive CTEs
- [ ] Subqueries: correlated vs uncorrelated
- [ ] NULL semantics — the biggest source of wrong answers
- [ ] Index usage and EXPLAIN basics

## Online-assessment angle
Typical OA: 3-5 queries, increasing difficulty, ending with a window-function problem.

## Interview angle
Be ready to optimise a slow query and explain the plan.
