## How to use this vault

1. **Never read passively.** Every note ends with questions you must be able to answer cold.
2. **One file per topic**, named lowercase-with-dashes. Keep each under ~300 lines; split when it grows.
3. **Every wrong answer gets logged** in `10_Mistake_Log_and_Revision/mistake-log.md` the same day.
4. **Spaced repetition:** review a topic on day 1, 3, 7, 21. Track in `00_Start_Here/Trackers/`.
5. **OA prep is timed prep.** Solving untimed does not count. Log every mock in `06_Online_Assessments/06_Timed_Mock_Logs/`.

## Standard note template

```
# <Topic>
## 1. Core idea in 3 lines
## 2. Definitions & formulas
## 3. Worked example
## 4. Complexity / trade-offs
## 5. Common traps (OA)
## 6. Interview questions + crisp answers
## 7. Recall questions (self-test)
```

## Weekly rhythm (suggested)

- Mon-Fri: 1 DSA pattern + 1 core-CS topic + 30 min aptitude
- Sat: 1 full timed mock OA + review
- Sun: revision of the week's mistake log + 1 system design / ML design case
