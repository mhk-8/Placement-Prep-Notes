# Software Engineering & Tools

> Folder: `02_Core_CS/07_Software_Engineering`

## Why this matters
Light on theory, but git, testing and debugging come up in every interview conversation about your projects.

## Must-know checklist
- [ ] Git: branching, merge vs rebase, conflict resolution, reset vs revert
- [ ] Testing: unit/integration/e2e, mocking, TDD basics
- [ ] SDLC models: waterfall, agile, scrum ceremonies
- [ ] Code quality: readability, DRY, code review practice
- [ ] CI/CD basics; Docker fundamentals
- [ ] Debugging methodology; logging vs breakpoints

## Online-assessment angle
Occasionally an MCQ on git commands or agile terminology.

## Interview angle
'Walk me through your git workflow on your project' and 'how did you test it' are near-certain.
