# Computer Architecture

> Folder: `02_Core_CS/05_Computer_Architecture`

## Why this matters
Lower weight for software roles, higher for systems/hardware-adjacent teams and for IITM core-CS panels.

## Must-know checklist
- [ ] Number systems, IEEE 754 floating point
- [ ] Instruction cycle, ISA, RISC vs CISC
- [ ] Pipelining: stages, hazards (structural/data/control), forwarding, stalls, speedup formula
- [ ] Cache: direct-mapped, set-associative, fully associative; hit/miss; write-through vs write-back
- [ ] Memory hierarchy and locality
- [ ] Amdahl's law
- [ ] Instruction-level and thread-level parallelism

## Online-assessment angle
Pipeline speedup and cache hit-rate numericals appear in core-CS MCQ sections.

## Interview angle
Cache-friendly code and false sharing sometimes surface in performance discussions.
