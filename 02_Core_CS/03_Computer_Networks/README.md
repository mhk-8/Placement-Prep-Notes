# Computer Networks

> Folder: `02_Core_CS/03_Computer_Networks`

## Why this matters
Reliable MCQ points and a frequent interview warm-up ('what happens when you type a URL').

## Must-know checklist
- [ ] OSI vs TCP/IP layers and what each layer does
- [ ] TCP vs UDP; three-way handshake; four-way teardown
- [ ] Flow control, congestion control (slow start, AIMD), sliding window
- [ ] IP addressing, subnetting, CIDR, NAT
- [ ] DNS resolution end to end
- [ ] HTTP/1.1 vs 2 vs 3; methods, status codes, headers, cookies
- [ ] HTTPS: TLS handshake, certificates, symmetric vs asymmetric
- [ ] ARP, DHCP, ICMP
- [ ] Routing: distance vector vs link state
- [ ] Sockets; ports; well-known port numbers

## Online-assessment angle
Subnetting arithmetic and port/protocol matching are near-guaranteed MCQ items.

## Interview angle
'What happens when you type google.com and press enter' — rehearse a 3-minute layered answer.
