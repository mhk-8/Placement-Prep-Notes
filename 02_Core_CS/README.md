# 02 — Core Computer Science

> Folder: `02_Core_CS`

## Why this matters
Core CS carries the MCQ sections of most OAs and 20-40% of technical interview time. It is also the cheapest section to score in, because the question bank is finite and stable.

## Must-know checklist
- [ ] Explain each concept in 3 sentences without jargon
- [ ] Draw the standard diagrams from memory (process states, TCP handshake, ER model, memory layout)
- [ ] Know the numbers: page size, cache line, TCP vs UDP header sizes, isolation levels
- [ ] Connect theory to your own projects — interviewers probe the link

## Online-assessment angle
Core CS MCQs are high-speed, low-depth. Practise from `06_Online_Assessments/05_MCQ_Core_CS_Banks`.

## Interview angle
Depth over breadth: expect 3-4 follow-ups on whichever topic you claim strength in.
