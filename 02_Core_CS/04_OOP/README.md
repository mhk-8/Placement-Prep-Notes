# Object-Oriented Programming

> Folder: `02_Core_CS/04_OOP`

## Why this matters
Tested in MCQs, in LLD rounds, and implicitly in every code review of your solution.

## Must-know checklist
- [ ] Four pillars with a real example each, not textbook definitions
- [ ] Overloading vs overriding; static vs dynamic dispatch
- [ ] Abstract class vs interface; when to use which
- [ ] Composition over inheritance; the diamond problem
- [ ] SOLID principles with a violation and a fix for each
- [ ] Constructors, destructors, copy/move semantics (C++), garbage collection (Java/Python)
- [ ] Access modifiers; static members; virtual tables
- [ ] Exception handling design

## Online-assessment angle
MCQs on output-prediction with inheritance and virtual functions are common — practise reading tricky snippets.

## Interview angle
You will be asked to design a class hierarchy live. Justify every inheritance relationship with 'is-a'.
