# 99 — Resources & Archive

Reference material and anything you are not actively using. Keeps the working folders clean.

## Suggested structure
```
Books/            # PDFs, textbook chapters (CLRS, OSTEP, Korth, Kurose, Bishop, Goodfellow, ISLR)
Courses/          # course notes, slides, assignment solutions from your M.Tech coursework
Links/            # links.md — curated, annotated, one line on why each is worth returning to
Old_Notes/        # previous semesters' notes, pre-reorganisation material
Templates/        # note templates, resume templates, code templates
```

## Curation rule
A link belongs here only with a one-line note on what it is good for. An uncurated link dump gets read zero times.

## Worth having in `Links/links.md`
Problem sets you have committed to (one primary list, not five), the official docs for your primary language, company engineering blogs for your target companies, and the two or three YouTube/course sources you actually learn well from. Resist collecting more.
