# 08 — Company-Wise

One folder per target company. Create it the day you decide to apply.

## Folder template

```
<Company>/
  00-process.md        # rounds, timeline, eligibility, CTC, locations
  01-oa-pattern.md     # platform, sections, duration, negative marking, past questions
  02-past-questions.md # coding + MCQ + interview questions from seniors, Glassdoor, LeetCode discuss
  03-tech-stack.md     # what they use; skim their engineering blog
  04-prep-plan.md      # the 1-2 week focused plan before their OA
  05-debrief.md        # what actually happened, filled in after each round
```

## Companies worth a folder (edit for your shortlist)

Amazon, Microsoft, Google, Goldman Sachs, Uber, Oracle, Adobe, Salesforce, Qualcomm, Texas Instruments, Nvidia, Samsung R&D, Flipkart, Zomato/Swiggy, Atlassian, ServiceNow, Sprinklr, DE Shaw, Tower Research, Graviton, Jane Street, American Express, JPMorgan, Walmart Global Tech, PhonePe, Rakuten, Media.net, Arcesium, Databricks, Palantir, and the AI/ML-specific ones on your list.

## What differentiates the good folders

- Past questions collected from **your own seniors** — placement cell archives beat any public source.
- A note on **what that company optimises for**: Amazon → leadership principles + DSA; Google → algorithmic depth; Goldman/DE Shaw → probability and puzzles; Samsung → core CS + C; ML startups → project depth and shipping ability.
- Your prep plan written as a dated checklist, not as intentions.
