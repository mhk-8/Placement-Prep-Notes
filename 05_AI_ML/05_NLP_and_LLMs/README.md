# NLP & LLMs

> Folder: `05_AI_ML/05_NLP_and_LLMs`

## Why this matters
The highest-signal current topic. Strength here differentiates sharply in 2026 hiring.

## Must-know checklist
- [ ] Text preprocessing; tokenisation (BPE, WordPiece, SentencePiece)
- [ ] Embeddings: word2vec, GloVe, contextual embeddings
- [ ] seq2seq, attention, transformer architecture in full
- [ ] BERT vs GPT: encoder vs decoder, pretraining objectives
- [ ] Fine-tuning vs prompting; LoRA/PEFT; instruction tuning; RLHF/DPO
- [ ] Decoding: greedy, beam, top-k, top-p, temperature
- [ ] RAG: chunking, embeddings, vector DBs, retrieval quality, reranking
- [ ] Evaluation: perplexity, BLEU/ROUGE, task benchmarks, LLM-as-judge and its limits
- [ ] Hallucination, context length, KV cache, inference cost
- [ ] Agents and tool use; guardrails

## Online-assessment angle
MCQs on tokenisation, attention complexity (O(n²)) and decoding parameters.

## Interview angle
If you have an LLM project, expect the entire round to be about it. Know your chunking strategy and why.
