# ML System Design

> Folder: `05_AI_ML/08_ML_System_Design`

## Why this matters
The ML equivalent of the HLD round; increasingly standard for AI/ML roles.

## Must-know checklist
- [ ] Framework: business goal → ML framing → data → features → model → offline metric → online metric → serving → monitoring → iteration
- [ ] Framing problems as classification/ranking/regression and choosing the right target
- [ ] Training-serving skew; offline-online metric mismatch
- [ ] Cold start; feedback loops; position bias
- [ ] Case studies: recommendation feed, search ranking, fraud detection, ad CTR prediction, spam/abuse detection, churn prediction, RAG chatbot, ETA prediction

## Online-assessment angle
Not an OA topic.

## Interview angle
Spend the first 5 minutes on requirements and metrics. Candidates who jump to model choice lose this round.
