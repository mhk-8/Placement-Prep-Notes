# 05 — AI / ML

> Folder: `05_AI_ML`

## Why this matters
For AI/ML and data-science roles this section replaces roughly half the weight of DSA. Interviews probe mathematical depth, practical judgement and your own projects, in that order.

## Must-know checklist
- [ ] Derive, don't recite: be able to derive gradient descent, backprop for one layer, bias-variance decomposition
- [ ] Explain every algorithm's assumptions, cost function, complexity and failure modes
- [ ] Know how to diagnose a badly-performing model systematically
- [ ] Be able to defend every choice in your own projects with a metric
- [ ] Stay current: transformers, LLM fine-tuning, RAG, evaluation

## Online-assessment angle
ML OAs mix core-CS coding with ML MCQs (metrics, overfitting, math) and occasionally a small notebook task on a dataset.

## Interview angle
Two halves: theory depth (math) and applied judgement ('your model has 99% accuracy and is useless — why?').
