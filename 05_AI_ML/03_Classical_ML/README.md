# Classical Machine Learning

> Folder: `05_AI_ML/03_Classical_ML`

## Why this matters
Still the majority of interview questions, even at LLM-heavy companies.

## Must-know checklist
- [ ] Supervised vs unsupervised vs reinforcement; the ML workflow
- [ ] Linear & logistic regression: assumptions, cost functions, regularisation (L1 vs L2)
- [ ] Bias-variance trade-off; overfitting/underfitting diagnosis; learning curves
- [ ] Decision trees: entropy, gini, information gain, pruning
- [ ] Ensembles: bagging, random forest, boosting (AdaBoost, GBM, XGBoost), stacking
- [ ] SVM: margin, kernels, the dual, C and gamma
- [ ] kNN; Naive Bayes; their assumptions
- [ ] Clustering: k-means (+ its failure modes), hierarchical, DBSCAN, GMM/EM
- [ ] Dimensionality reduction: PCA, t-SNE, UMAP
- [ ] Metrics: accuracy, precision, recall, F1, ROC-AUC, PR-AUC, log loss, RMSE/MAE/R²; which to use when
- [ ] Cross-validation; data leakage; class imbalance (SMOTE, class weights, threshold tuning)

## Online-assessment angle
MCQs on metric selection, regularisation and overfitting dominate. Know precision vs recall trade-offs cold.

## Interview angle
'Which model would you pick and why' — always answer with data size, interpretability, latency and the cost of each error type.
