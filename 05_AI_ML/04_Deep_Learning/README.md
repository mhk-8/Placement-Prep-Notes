# Deep Learning

> Folder: `05_AI_ML/04_Deep_Learning`

## Why this matters
Expected depth for AI/ML roles; backpropagation is the single most-asked derivation.

## Must-know checklist
- [ ] Perceptron → MLP; forward and backward pass by hand
- [ ] Activations: sigmoid, tanh, ReLU, LeakyReLU, GELU, softmax — and vanishing/exploding gradients
- [ ] Loss functions: cross-entropy, MSE, contrastive, focal
- [ ] Optimisers: SGD, momentum, RMSProp, Adam, AdamW; learning-rate schedules
- [ ] Regularisation: dropout, weight decay, early stopping, data augmentation, label smoothing
- [ ] Normalisation: batch, layer, group — and why layer norm dominates in transformers
- [ ] CNNs: convolution arithmetic, pooling, receptive field, parameter counting
- [ ] RNN/LSTM/GRU: gates and the vanishing gradient fix
- [ ] Attention and transformers: Q/K/V, multi-head, positional encoding
- [ ] Weight initialisation; residual connections
- [ ] Training diagnostics: loss not decreasing, overfitting, NaNs

## Online-assessment angle
Parameter-counting and output-shape questions for CNNs are frequent MCQs — practise the arithmetic.

## Interview angle
'Derive backprop for a 2-layer network', 'why does self-attention scale by sqrt(d_k)?', 'batch norm at train vs inference'.
