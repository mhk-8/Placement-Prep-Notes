# Data Handling & Feature Engineering

> Folder: `05_AI_ML/09_Data_Handling_and_Feature_Engineering`

## Why this matters
The work that actually moves metrics, and where practical experience shows.

## Must-know checklist
- [ ] numpy vectorisation; broadcasting
- [ ] pandas: groupby, merge, pivot, apply vs vectorised ops, memory tricks
- [ ] Missing values: MCAR/MAR/MNAR and imputation strategy
- [ ] Outlier detection and treatment
- [ ] Encoding: one-hot, label, target, frequency, embeddings
- [ ] Scaling: standard, min-max, robust — and which models need it
- [ ] Feature selection: filter, wrapper, embedded; importance and SHAP
- [ ] Time-based features; leakage from future information
- [ ] Train/val/test splitting: random vs time-based vs group-based
- [ ] Sampling and imbalanced data handling

## Online-assessment angle
Some ML OAs include a pandas/numpy coding section — practise timed data-wrangling.

## Interview angle
Data leakage is a favourite trap question. Be able to name three ways it sneaks in.
