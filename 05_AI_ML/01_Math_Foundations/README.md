# Mathematical Foundations

> Folder: `05_AI_ML/01_Math_Foundations`

## Why this matters
Linear algebra and calculus underpin every model; IITM panels probe this hard.

## Must-know checklist
- [ ] Vectors, matrices, rank, determinant, inverse
- [ ] Eigenvalues/eigenvectors; diagonalisation; SVD
- [ ] Matrix calculus: gradients, Jacobian, Hessian, chain rule
- [ ] Norms (L1/L2), inner products, orthogonality, projections
- [ ] Convexity; positive definiteness
- [ ] Optimisation: gradient descent, SGD, momentum, Adam; convergence intuition
- [ ] Lagrange multipliers and constrained optimisation (→ SVM)
- [ ] PCA derived from SVD / covariance eigendecomposition

## Online-assessment angle
Matrix-dimension and eigenvalue MCQs; occasionally numpy coding tasks.

## Interview angle
'Derive the gradient of MSE for linear regression', 'why does PCA use eigenvectors of the covariance matrix?'
