# Computer Vision

> Folder: `05_AI_ML/06_Computer_Vision`

## Why this matters
Relevant if your projects are vision-based; otherwise keep it at conceptual depth.

## Must-know checklist
- [ ] Image fundamentals: channels, filters, convolution, edge detection
- [ ] CNN architectures: LeNet, AlexNet, VGG, ResNet (skip connections), Inception, EfficientNet
- [ ] Object detection: R-CNN family, YOLO, SSD; IoU, NMS, mAP
- [ ] Segmentation: semantic vs instance; U-Net, Mask R-CNN
- [ ] Transfer learning and fine-tuning strategy
- [ ] Augmentation
- [ ] Vision transformers; CLIP; diffusion basics

## Online-assessment angle
Output-shape and receptive-field calculations.

## Interview angle
Be able to explain why ResNet's skip connections enable very deep networks.
