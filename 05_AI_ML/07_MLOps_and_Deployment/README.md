# MLOps & Deployment

> Folder: `05_AI_ML/07_MLOps_and_Deployment`

## Why this matters
Separates people who have trained models from people who have shipped them.

## Must-know checklist
- [ ] Experiment tracking and reproducibility (MLflow, W&B, seeds, versioning)
- [ ] Data and model versioning; feature stores
- [ ] Serving: batch vs real-time, REST/gRPC, model servers, ONNX
- [ ] Latency/throughput optimisation: quantisation, distillation, pruning, batching
- [ ] Monitoring: data drift, concept drift, performance decay, alerting
- [ ] CI/CD for ML; retraining pipelines
- [ ] Docker/Kubernetes basics; cloud ML services
- [ ] Cost awareness: GPU hours, inference cost per request

## Online-assessment angle
Rarely in OAs.

## Interview angle
'How would you deploy this model and know when it breaks?' — have a concrete answer from your own project.
