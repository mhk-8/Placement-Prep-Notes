
# Reading Comprehension — Strategy Under Time Pressure

> **Why it matters.** RC is usually the **highest-mark, lowest-accuracy** part of a verbal section:
> one passage carries 3-5 questions, but candidates run out of time or over-interpret. The fix is
> almost entirely **method**, not vocabulary.

---

## 1. The time arithmetic ⭐⭐⭐

A typical verbal section gives you 25 minutes for ~25 questions, of which 8-10 are RC across two
passages. That means:

```
Per passage (5 questions):  ~5 minutes total
   Reading        : 2 - 2.5 minutes  for a 400-500 word passage
   Questions      : ~35 seconds each
```

⚠️ **If you cannot finish a passage's questions in 5 minutes, the passage has beaten you.** Skip
it, answer the grammar/vocabulary questions (which are 20-30 seconds each), and return only if time
remains. Two grammar questions are worth the same as two RC questions and cost a quarter of the
time.

---

## 2. Which approach — and when ⭐⭐

There are three standard approaches. **Which one is right depends on the passage type**, so learn
to classify in the first ten seconds.

| Approach | Method | Best for |
|---|---|---|
| **Read-then-answer** | Read the passage fully (skimming), then answer | Short passages (< 350 words), narrative or argumentative passages, and when most questions are inference/tone |
| **Questions-first** | Skim the questions, then read hunting for answers | Long, dense, factual passages (science, economics) with mostly detail questions ⭐ |
| **Skim-and-map** | Read the first and last sentence of each paragraph, build a mental map, then answer with targeted re-reads | Long passages of any type — the best general-purpose compromise ⭐⭐⭐ |

> **Default recommendation:** use **skim-and-map**. It gives you the structure (which answers all
> main-idea, tone and structure questions) in 90 seconds, and leaves you knowing exactly which
> paragraph to return to for every detail question.

---

## 3. The skim-and-map technique ⭐⭐⭐

```
PASS 1 (60-90 seconds) — build the map. Do NOT try to absorb detail.
   • Read the FIRST and LAST sentence of every paragraph.
   • Read any sentence containing a contrast marker (but, however, yet, although,
     nevertheless, on the contrary, in contrast) — these carry the author's real position. ⭐
   • Note, in the margin, ONE WORD per paragraph:  P1: problem   P2: cause
     P3: counterview   P4: author's solution
   • Identify the author's TONE in one word: critical / supportive / neutral / analytical /
     cautionary / optimistic.

PASS 2 — answer the questions, returning to the mapped paragraph for details.
```

**Why the first and last sentences?** In expository prose the first sentence of a paragraph is
usually the topic sentence and the last is the transition or conclusion. Between them sits the
evidence, which you only need if a question asks for it.

---

## 4. Question types and how each is solved ⭐⭐⭐

| Type | Signal words | Method |
|---|---|---|
| **Main idea / central theme** | "primary purpose", "best title", "mainly concerned with" | The answer covers the **whole** passage, not one paragraph. Eliminate options that are too narrow (only P2) or too broad (the whole field) ⭐ |
| **Detail / fact** | "According to the passage…" | **The answer is literally in the text.** Locate it, do not reason. If you cannot find it, it is not the answer ⚠️ |
| **Inference** | "It can be inferred", "The author implies", "suggests" | One small step beyond the text — no more. The correct answer *must* be supported; the wrong answers are one step too far ⭐⭐ |
| **Tone / attitude** | "The author's attitude is…" | Look at adjectives and adverbs. Most academic passages are **measured**, so extreme options (scornful, ecstatic) are usually wrong ⭐ |
| **Vocabulary in context** | "The word X, as used in line n, means…" | **Ignore the dictionary definition.** Substitute each option into the sentence and read it aloud mentally ⭐⭐ |
| **Structure / function** | "The second paragraph serves to…" | Ask what *job* the paragraph does: introduce, give evidence, raise an objection, concede, conclude |
| **Strengthen / weaken** | "Which of the following would most weaken…" | Find the author's core claim, then ask which option attacks its assumption |
| **Except / NOT** | "All of the following are mentioned EXCEPT" | ⚠️ The answer is the one **not** in the text. Tick off the three you can find; the remaining one is the answer |

---

## 5. Elimination heuristics ⭐⭐⭐

RC is a multiple-choice test, so **eliminating is faster than finding**. These patterns identify
wrong options reliably:

```
1. EXTREME LANGUAGE → usually wrong.
   Words like always, never, all, none, must, only, impossible, entirely, completely.
   Academic authors hedge; so do correct answers: often, may, tends to, generally, suggests. ⭐⭐

2. OUTSIDE KNOWLEDGE → wrong, even if the statement is TRUE in reality. ⚠️⭐⭐⭐
   The passage is the only admissible evidence. This is the single hardest habit to build.

3. HALF-RIGHT OPTIONS → wrong. An option that is correct in its first clause and wrong in its
   second is wrong. Read the WHOLE option. ⭐

4. TOO NARROW for a main-idea question → wrong. If it only covers paragraph 3, it is not the
   main idea.

5. TOO BROAD / too general → wrong. "Science is important" is not the main idea of a passage
   about a specific experiment.

6. REVERSED RELATIONSHIPS → wrong. The passage says A causes B; the option says B causes A.
   Check the direction of every causal claim. ⭐

7. WORD-FOR-WORD ECHOES can be traps. An option that repeats the passage's vocabulary but
   recombines it into a claim the passage never made is a common distractor. ⚠️

8. If two options are OPPOSITES, the answer is often one of them — the test-writer wrote the
   distractor by flipping the correct answer.
```

---

## 6. Passage types and what to expect

| Type | Typical structure | What is asked |
|---|---|---|
| **Science / technology** | Phenomenon → mechanism → implication | Detail and inference; vocabulary is technical but defined in context |
| **Social science / economics** | Claim → evidence → counter-evidence → qualified conclusion | Main idea, author's position, strengthen/weaken |
| **Philosophy / abstract** | Thesis → objection → response | Inference and structure; the hardest type ⚠️ |
| **Business / current affairs** | Situation → problem → options → recommendation | Detail and application |
| **Narrative / literary** | Scene, character, event | Tone, inference about character |

⭐ **For dense abstract passages, the reliable move is to track only the author's position**, not
the argument's internals: who is the author agreeing with, and who are they disagreeing with?

## 7. A fully worked RC example ⭐⭐

**Passage (approx. 300 words)**

> For most of the twentieth century, urban planners treated the automobile as the organising
> principle of the modern city. Roads were widened, parking was mandated, and neighbourhoods were
> reshaped around the assumption that mobility meant driving. The results were, by their own
> metrics, a success: journey times fell, and car ownership rose steadily across the developed
> world.
>
> Yet the accounting was incomplete. The benefits of automobile-centric planning were concentrated
> among those who owned cars, while its costs — noise, air pollution, road deaths, and the
> severing of walkable neighbourhoods — were distributed across the entire population, falling
> most heavily on those least able to afford a vehicle. Congestion, moreover, proved stubbornly
> resistant to the obvious remedy. Each new lane attracted new drivers until travel times returned
> to their prior equilibrium, a phenomenon economists came to call induced demand.
>
> Some planners have responded by inverting the original assumption. Rather than asking how many
> cars a street can carry, they ask how many *people* it can move, and by what means. Under this
> framing, a bus lane that carries two thousand passengers an hour outperforms three car lanes
> that carry eighteen hundred. The shift is not anti-car so much as anti-assumption; it treats the
> private vehicle as one mode among several rather than as the default around which everything
> else must bend.
>
> Whether this reframing will prove durable is unclear. It requires political capital, since the
> costs of change are immediate and visible while the benefits are diffuse and delayed. But the
> intellectual case against treating mobility and driving as synonymous now appears difficult to
> dislodge.

**The map (what you would write in the margin during pass 1):**
```
P1: old model — car as organising principle; "successful" by its own metrics
P2: BUT the accounting was incomplete — costs spread, benefits concentrated; induced demand
P3: new framing — move PEOPLE not cars; not anti-car, anti-assumption
P4: uncertain politically, but the intellectual case is settled
Tone: analytical, mildly favourable to the new framing
```

---

**Q1. The primary purpose of the passage is to:**
```
(a) argue that automobiles should be banned from city centres
(b) describe a shift in how planners conceive of urban mobility
(c) explain the economic theory of induced demand
(d) criticise twentieth-century planners for incompetence
```
<details><summary>Answer and reasoning</summary>

**(b).**
- (a) is **extreme** and unsupported — the passage explicitly says the shift "is not anti-car".
- (c) is **too narrow** — induced demand is one paragraph's supporting detail, not the purpose.
- (d) is **too strong in tone**; the passage says the old approach succeeded "by its own metrics",
  which is a measured judgement, not an accusation of incompetence.
- (b) covers P1 (old model), P3 (new model) and P4 (its prospects) — the whole passage. ✓

⭐ Note how three of the four wrong answers were eliminated by the standard heuristics (extreme,
too narrow, wrong tone) without needing to re-read the passage.
</details>

---

**Q2. According to the passage, induced demand refers to:**
```
(a) the rising demand for cars as incomes grow
(b) the tendency of new road capacity to attract additional drivers
(c) the public's demand for better public transport
(d) the demand created by planners for wider roads
```
<details><summary>Answer and reasoning</summary>

**(b).** This is a **detail** question — the answer is literally in P2: *"Each new lane attracted
new drivers until travel times returned to their prior equilibrium."*

(a) is a real-world true statement but is **not what the passage defines** — the outside-knowledge
trap. (c) and (d) are not stated at all.
</details>

---

**Q3. It can be inferred that the author regards the costs of automobile-centric planning as:**
```
(a) negligible compared with its benefits
(b) borne disproportionately by non-drivers
(c) impossible to quantify
(d) entirely the fault of individual drivers
```
<details><summary>Answer and reasoning</summary>

**(b).** P2 states the costs fell "most heavily on those least able to afford a vehicle" — the
inference is one short step from that.

- (a) reverses the author's position.
- (c) is **extreme** ("impossible") and unsupported — the author in fact lists the costs, implying
  they can be identified.
- (d) is unsupported; the passage blames a planning *assumption*, not individuals.
</details>

---

**Q4. The word "dislodge" in the final sentence most nearly means:**
```
(a) physically remove          (b) overturn          (c) postpone          (d) ignore
```
<details><summary>Answer and reasoning</summary>

**(b).** Substitute each into the sentence:
*"the intellectual case … now appears difficult to **overturn**"* — reads correctly.
*"difficult to physically remove"* — the literal dictionary sense, wrong in context. ⚠️ This is
exactly the trap: the most literal meaning is usually not the answer in a vocabulary-in-context
question.
</details>

---

**Q5. Which of the following, if true, would most weaken the argument in the third paragraph?**
```
(a) Bus lanes are expensive to construct.
(b) In several cities, converting car lanes to bus lanes reduced total person-throughput because
    ridership never materialised.
(c) Some drivers object to bus lanes.
(d) Induced demand has been observed in public transport systems as well.
```
<details><summary>Answer and reasoning</summary>

**(b).** P3's argument rests on a specific claim: that a bus lane moves *more people* than the car
lanes it replaces. (b) attacks precisely that claim with a counter-example.

- (a) attacks cost, which the paragraph never claims is low — irrelevant to the argument as stated.
- (c) is about preference, not throughput.
- (d) is interesting but does not undermine the person-throughput comparison.

⭐ **The method for strengthen/weaken:** state the argument's *conclusion* and its *key premise* in
one line each, then ask which option attacks the premise. Here: conclusion = "measure people, not
cars"; premise = "doing so favours buses because they move more people". Attack the premise.
</details>

## 8. Building reading speed ⭐

Speed comes from two things, and neither is "reading faster":
```
1. SUBVOCALISATION REDUCTION — stop saying every word in your head. Practise by running a
   finger/cursor slightly faster than comfortable and forcing your eyes to keep up.
2. CHUNKING — read in phrases, not words. "The results were, by their own metrics, a success"
   is three chunks, not nine words.
3. VOCABULARY — every unknown word costs a full stop-and-restart. The fix is reading, not lists.
```

**A realistic target:** 200-250 words per minute with 80% comprehension is enough for any OA.
Competitive-exam claims of 600 wpm are not useful for a test that asks detail questions.

**Daily practice (20 minutes):**
```
10 min : read one long-form article (The Hindu editorial, Aeon, The Economist, a science
         explainer). Afterwards, write the main idea and the author's tone in ONE line each.
10 min : one timed RC passage with questions, then analyse EVERY wrong answer:
           Was it a misread? An inference pushed too far? Outside knowledge? Ran out of time?
```

Logging the **cause** of each wrong answer is what produces improvement. Use the mistake table in
`../06_Timed_Mock_Logs/Mock_Test_Template.md`.

## 9. Other verbal question types (quick reference)

### Para-jumbles (sentence rearrangement) ⭐⭐
```
1. FIND THE OPENING SENTENCE. It introduces a subject by full name, contains no pronoun with an
   unstated antecedent, and no connector (however, therefore, moreover). ⭐
2. FOLLOW THE PRONOUN CHAINS. A sentence beginning "It", "This", "He", "Such" must follow the
   sentence that introduces that referent.
3. FOLLOW THE CONNECTORS. "However" signals a contrast with the immediately preceding idea;
   "therefore" signals a consequence.
4. LOOK FOR MANDATORY PAIRS — two sentences that must be adjacent. Lock them together and treat
   them as one unit; this often eliminates most options immediately. ⭐⭐
5. CHECK THE OPTIONS. If three of four options start with sentence C, do not waste time deciding
   the first sentence — work on the later positions instead. ⭐ This alone saves a minute.
```

### Sentence completion / fill in the blanks
```
1. Read the WHOLE sentence first; the clue is usually after the blank.
2. Identify the DIRECTION: does the sentence continue an idea or reverse it?
   "although / despite / yet / but" → the blank contrasts with what precedes it. ⭐
   "moreover / furthermore / because / since" → the blank continues.
3. Predict a word yourself BEFORE looking at the options, then find the closest match. ⭐⭐
4. For two-blank questions, solve the easier blank first and eliminate.
```

### Vocabulary
```
Learn WORD ROOTS rather than lists — they generalise:
  bene- (good): benefit, benevolent, benign        mal- (bad): malice, malign, malady
  pre- (before): precede, premonition              post- (after): posthumous, postpone
  ambi-/amphi- (both): ambiguous, ambivalent       omni- (all): omnipotent, omniscient
  -phile (love): bibliophile                       -phobe (fear): xenophobe
  chron (time): chronology, anachronism            loqu/loc (speak): loquacious, eloquent
  vid/vis (see): evident, visionary                cred (believe): credible, incredulous
  ped (foot/child): pedestrian, pedagogy           magn (great): magnanimous, magnitude
```
⭐ In context questions, the root plus the sentence's direction (positive/negative) usually
identifies the answer without knowing the word.
