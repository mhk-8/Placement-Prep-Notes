# OA Patterns by Company

> Folder: `06_Online_Assessments/01_OA_Patterns_by_Company`

## Why this matters
Each company reuses its format year after year. Knowing the format is worth several marks.

## Must-know checklist
- [ ] Platform (HackerRank / HackerEarth / Codility / CodeSignal / Mettl / in-house)
- [ ] Number of sections, duration, negative marking, whether you can revisit questions
- [ ] Typical question types and difficulty band
- [ ] Whether webcam/proctoring and tab-switch detection are used
- [ ] Historical cutoff if known
- [ ] Past questions collected from seniors and public sources

## Online-assessment angle
Create one file per company: `amazon-oa.md`, `microsoft-oa.md`, etc., and update it after every attempt.

## Interview angle
Ask seniors and the placement cell for recent patterns — this is the highest-return 30 minutes of prep you can do.
