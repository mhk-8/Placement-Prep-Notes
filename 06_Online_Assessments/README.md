# 06 — Online Assessments

> Folder: `06_Online_Assessments`

## Why this matters
The OA is a filter, not a test of depth. It rewards pattern recognition, typing speed, time allocation and composure. Most strong candidates who fail, fail here.

## Must-know checklist
- [ ] Know each target company's OA format, duration, sections and cutoff before the test
- [ ] Practise strictly timed — untimed practice builds false confidence
- [ ] Have a time-allocation rule: read all problems first, solve easiest first, never sink 30 min into one
- [ ] Set up your environment: template file, fast I/O, debug snippets ready
- [ ] Partial scoring is common — submit a brute force before optimising
