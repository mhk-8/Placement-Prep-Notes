## 2. The fraction ↔ percentage table ⭐⭐⭐

**This single table is worth more marks than any formula in this folder.** Percentages, profit and
loss, ratios, data interpretation and time-work all collapse into fractions.

| Fraction | % | Fraction | % | Fraction | % |
|---|---|---|---|---|---|
| 1/2 | 50 | 1/8 | 12.5 | 1/14 | 7.14 |
| 1/3 | 33.33 | 3/8 | 37.5 | 1/15 | 6.67 |
| 2/3 | 66.67 | 5/8 | 62.5 | 1/16 | 6.25 |
| 1/4 | 25 | 7/8 | 87.5 | 1/18 | 5.55 |
| 3/4 | 75 | 1/9 | 11.11 | 1/20 | 5 |
| 1/5 | 20 | 2/9 | 22.22 | 1/24 | 4.17 |
| 2/5 | 40 | 4/9 | 44.44 | 1/25 | 4 |
| 3/5 | 60 | 1/10 | 10 | 1/30 | 3.33 |
| 4/5 | 80 | 1/11 | 9.09 | 1/40 | 2.5 |
| 1/6 | 16.67 | 1/12 | 8.33 | 1/50 | 2 |

| 1/7 | 14.28 | 7/12 | 58.33 | 1/80 | 1.25 |
| 2/7 | 28.57 | 1/13 | 7.69 | 1/100 | 1 |

**The 1/7 family (memorise the cycle):** 1/7 = 0.142857 repeating. The digits **142857** rotate:
2/7 = .285714, 3/7 = .428571, 4/7 = .571428, 5/7 = .714285, 6/7 = .857142.

> **Use it in reverse.** "Increase by 12.5%" means "multiply by 9/8". "A discount of 16⅔%" means
> "multiply by 5/6". Working in fractions avoids decimal arithmetic entirely.

## 3. Multiplication shortcuts

| Trick | Rule | Example |
|---|---|---|
| ×11 | Write outer digits, insert the sum between | 43×11 → 4 |7| 3 = 473; carry if > 9: 78×11 → 7|15|8 → 858 |
| ×5 | ×10, then ÷2 | 86×5 = 860/2 = 430 |
| ×25 | ×100, then ÷4 | 68×25 = 6800/4 = 1700 |
| ×125 | ×1000, then ÷8 | 48×125 = 48000/8 = 6000 |
| ×9, ×99 | ×10 − itself; ×100 − itself | 47×9 = 470−47 = 423 |
| ×15 | ×10 + half of that | 24×15 = 240+120 = 360 |
| Squares ending in 5 | `d5² = d(d+1) | 25` | 75² = 7×8 | 25 = 5625 |
| Near a base | `(b+a)(b+c) = b² + b(a+c) + ac` | 103×107 = 10000 + 1000 + 21 = 11021 |
| Difference of squares | `a²−b² = (a+b)(a−b)` | 84²−16² = 100×68 = 6800 |
| Numbers near 100 | `(100−a)(100−b) = 100(100−a−b) + ab` | 96×93 = 100×89 + 28 = 8928 |
| Split the multiplier | 37×12 = 37×10 + 37×2 | = 370 + 74 = 444 |

## 4. Divisibility rules

| By | Rule |
|---|---|
| 2 | Last digit even |
| 3 | Digit sum divisible by 3 |
| 4 | Last **two** digits divisible by 4 |
| 5 | Ends in 0 or 5 |
| 6 | Divisible by 2 **and** 3 |
| 7 | Double the last digit, subtract from the rest; repeat (e.g. 343 → 34 − 6 = 28 ✓) |
| 8 | Last **three** digits divisible by 8 |
| 9 | Digit sum divisible by 9 |
| 10 | Ends in 0 |
| 11 | (Sum of odd-position digits) − (sum of even-position digits) divisible by 11 |
| 12 | Divisible by 3 **and** 4 |
| 13 | Multiply last digit by 4, add to the rest; repeat |
| 25 | Last two digits are 00, 25, 50 or 75 |

## 5. Approximation discipline ⭐

Most aptitude options are far apart. **Estimate first, compute only if two options are close.**

```
 4783 × 0.0207  →  4800 × 0.02 = 96   → pick the option near 96
 (37.2% of 1480) → 37.5% = 3/8 → 1480 × 3/8 = 555 → answer ≈ 550
 √1720           → between 41² = 1681 and 42² = 1764 → ≈ 41.5
```

**Percentage-change approximations:**
```
Successive changes of a% then b%:  net = a + b + ab/100
  +20% then −20%  →  20 − 20 − 400/100 = −4%      (always a net LOSS)
  +10% then +10%  →  10 + 10 + 100/100 = +21%
```

## 6. Useful constants and identities

```
Σ(1..n)      = n(n+1)/2
Σ(1..n)²     = n(n+1)(2n+1)/6
Σ(1..n)³     = [n(n+1)/2]²
Sum of first n odd numbers  = n²
Sum of first n even numbers = n(n+1)

√2 = 1.414   √3 = 1.732   √5 = 2.236   √6 = 2.449   √7 = 2.646   √10 = 3.162
π  = 3.1416  e = 2.718
log10 2 = 0.3010   log10 3 = 0.4771   log10 5 = 0.6990   log10 7 = 0.8451

(a+b)² = a² + 2ab + b²          (a−b)² = a² − 2ab + b²
a² − b² = (a+b)(a−b)
(a+b)³ = a³ + b³ + 3ab(a+b)
a³ + b³ = (a+b)(a² − ab + b²)   a³ − b³ = (a−b)(a² + ab + b²)
a³ + b³ + c³ − 3abc = (a+b+c)(a² + b² + c² − ab − bc − ca)
If a + b + c = 0 then a³ + b³ + c³ = 3abc     ⭐ appears surprisingly often
```

## 7. Unit conversions that appear in aptitude

```
1 km/h  = 5/18 m/s          1 m/s = 18/5 km/h      ⭐⭐⭐ memorise both directions
1 mile  ≈ 1.609 km          1 inch = 2.54 cm
1 litre = 1000 cm³          1 m³ = 1000 litres
1 hectare = 10,000 m²       1 acre ≈ 4047 m²
1 day = 86400 s             1 year ≈ 365 days (use 360 for interest problems unless told otherwise)
1 dozen = 12                1 gross = 144        1 score = 20
1 quintal = 100 kg          1 tonne = 1000 kg
```

## 8. The 20-minute daily drill ⭐⭐⭐

```
 5 min : tables 12-25, squares to 40, the fraction-percentage table — recite, do not read
 5 min : 40 two-digit multiplications and divisions, timed, written
 5 min : 10 percentage-change and ratio questions, mental only
 5 min : 5 mixed word problems from whichever topic file you are on
```

Log your daily score. This is a pure drill skill: it improves quickly for about three weeks and
then plateaus, so **start it in week one**, not the week before the test.
