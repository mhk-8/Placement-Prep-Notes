# Core CS MCQ Banks

> Folder: `06_Online_Assessments/05_MCQ_Core_CS_Banks`

## Why this matters
Many OAs include 20-30 rapid core-CS MCQs with negative marking. Cheap marks if prepared, damaging if not.

## Must-know checklist
- [ ] OS: scheduling numericals, deadlock, paging, page replacement
- [ ] DBMS: normalisation, SQL output prediction, transactions
- [ ] CN: subnetting, protocol layers, port numbers
- [ ] OOP: output prediction with inheritance and virtual functions
- [ ] DSA: complexity of operations, traversal output, sorting properties
- [ ] Architecture: pipelining, cache
- [ ] Language-specific output-prediction snippets
- [ ] Aptitude-style complexity questions

## Online-assessment angle
Negative marking changes strategy: skip anything you are under ~60% confident on unless the section is unmarked.

## Interview angle
These same facts get asked conversationally, so the prep is not wasted.
