# Arrays & Strings

> Folder: `01_DSA/01_Arrays_and_Strings`

## Why this matters
The default input type. Most OA problems are dressed-up array or string problems.

## Must-know checklist
- [ ] Prefix sums, difference arrays, 2-D prefix sums
- [ ] Kadane's algorithm and variants
- [ ] In-place rotation, reversal, Dutch national flag
- [ ] String building costs; immutability in Java/Python
- [ ] KMP / Z-function / rolling hash basics
- [ ] Palindrome checks, anagram grouping

## Online-assessment angle
Watch for O(n^2) string concatenation in loops — the classic TLE in Python/Java.

## Interview angle
Expect follow-ups: 'now do it in O(1) extra space', 'now handle Unicode', 'now stream the input'.
