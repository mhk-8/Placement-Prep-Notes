# Complexity & Discrete Math

> Folder: `01_DSA/00_Complexity_and_Math`

## Why this matters
Everything else is measured in this language. Also covers the number-theory bits that show up in OAs.

## Must-know checklist
- [ ] Big-O / Theta / Omega, amortised analysis
- [ ] Master theorem and recurrence solving
- [ ] Logarithm and summation identities
- [ ] GCD/LCM, modular arithmetic, modpow, modular inverse
- [ ] Sieve of Eratosthenes, prime factorisation
- [ ] Combinatorics: nCr mod p, permutations, pigeonhole
- [ ] Overflow: when to use 64-bit, when to take mod

## Online-assessment angle
Mod 1e9+7 arithmetic and sieve appear constantly. Precompute factorials once.

## Interview angle
Be able to justify amortised O(1) for dynamic array push-back and for union-find with path compression.
