# Trees & BST

> Folder: `01_DSA/09_Trees_and_BST`

## Why this matters
Bread-and-butter of technical rounds.

## Must-know checklist
- [ ] All four traversals, recursive and iterative
- [ ] Level order / BFS variants, zigzag, right view
- [ ] Height, diameter, balance check
- [ ] LCA (binary tree and BST)
- [ ] BST insert/delete/validate; k-th smallest
- [ ] Serialize/deserialize; construct from traversals
- [ ] Segment-tree and Fenwick basics (see Advanced DS)

## Online-assessment angle
Tree problems in OAs usually arrive as array-encoded input — know the 2i+1/2i+2 indexing.

## Interview angle
Expect 'do it without recursion' and 'do it in O(1) space' (Morris traversal) as follow-ups.
