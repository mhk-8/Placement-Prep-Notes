# Advanced Data Structures

> Folder: `01_DSA/17_Advanced_DS`

## Why this matters
Occasionally decisive in harder OAs and in quant/research-flavoured rounds.

## Must-know checklist
- [ ] Fenwick / Binary Indexed Tree
- [ ] Segment tree (+ lazy propagation)
- [ ] Sparse table for static RMQ
- [ ] Disjoint set union (advanced uses)
- [ ] Balanced BST / ordered set in your language
- [ ] LRU/LFU cache design

## Online-assessment angle
Range-sum-with-updates problems mean Fenwick or segment tree; nothing else fits the constraints.

## Interview angle
LRU cache is a perennial interview implementation question — know it cold.
