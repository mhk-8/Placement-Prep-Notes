# Linked Lists

> Folder: `01_DSA/07_Linked_List`

## Why this matters
Low OA weight, high interview weight — it tests pointer discipline.

## Must-know checklist
- [ ] Reverse (iterative and recursive)
- [ ] Cycle detection and entry point (Floyd)
- [ ] Merge two / k sorted lists
- [ ] Remove n-th from end; reorder; partition
- [ ] Dummy-head technique
- [ ] Doubly linked list + hashmap for LRU cache

## Online-assessment angle
Rare in OAs except as part of an LRU cache implementation.

## Interview angle
Draw the pointers on paper before typing. Most failures here are careless, not conceptual.
