# Must-Do Problem List

> **~150 problems, ordered by pattern.** This is the floor, not the ceiling. Doing these 150 properly beats doing 500 superficially.
> A problem is **done** only when you can re-derive the approach cold three weeks later (`Trackers/problem-tracker.md` enforces this).

**Difficulty:** 🟢 easy · 🟡 medium · 🔴 hard · ⭐ = asked verbatim in real OAs often enough to be worth memorising

**Order:** follow the phase plan in `00_Start_Here/study-plan.md`, not this file top-to-bottom. Within a pattern, do the 🟢 first, then the ⭐, then the rest.
