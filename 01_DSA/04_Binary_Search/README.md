# Binary Search

> Folder: `01_DSA/04_Binary_Search`

## Why this matters
Half the 'hard' OA problems are binary search on the answer in disguise.

## Must-know checklist
- [ ] Exact search; lower_bound / upper_bound semantics
- [ ] Avoiding the mid-overflow and infinite-loop bugs
- [ ] Binary search on answer (minimise the maximum / maximise the minimum)
- [ ] Search in rotated sorted array; find peak
- [ ] Binary search on real numbers with epsilon
- [ ] Predicate monotonicity — the precondition you must state

## Online-assessment angle
If the problem says 'minimum possible maximum' or 'k-th smallest', reach for binary search on answer.

## Interview angle
Write the boundary conditions before the loop; interviewers watch specifically for off-by-one handling.
