# Two Pointers & Sliding Window

> Folder: `01_DSA/03_Two_Pointers_Sliding_Window`

## Why this matters
The go-to optimisation for subarray/substring problems on sorted or monotone data.

## Must-know checklist
- [ ] Fixed-size vs variable-size windows
- [ ] Shrink-while-invalid template
- [ ] Two pointers on sorted arrays (pair sum, 3-sum)
- [ ] Fast/slow pointers (cycle, midpoint)
- [ ] Longest substring without repeats; min window substring
- [ ] At-most-K trick to get exactly-K

## Online-assessment angle
Memorise one window template and adapt it — saves 5-10 minutes per OA problem.

## Interview angle
Be ready to prove why the window never needs to move backwards.
