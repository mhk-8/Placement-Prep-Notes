# Recursion & Backtracking

> Folder: `01_DSA/06_Recursion_Backtracking`

## Why this matters
The base for DP, trees, graphs and constraint problems.

## Must-know checklist
- [ ] Recursion tree, base cases, state definition
- [ ] Subsets, permutations, combinations (with duplicates)
- [ ] N-Queens, Sudoku, word search
- [ ] Pruning and constraint propagation
- [ ] Recursion to iteration; explicit stack
- [ ] Stack-depth limits (Python's 1000 default)

## Online-assessment angle
n<=20 in constraints almost always means exponential backtracking or bitmask DP is intended.

## Interview angle
Always state the state, the choice, and the constraint before coding.
