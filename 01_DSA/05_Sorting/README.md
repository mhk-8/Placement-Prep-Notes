# Sorting

> Folder: `01_DSA/05_Sorting`

## Why this matters
Rarely asked directly, constantly used as a subroutine, and a favourite MCQ topic in OAs.

## Must-know checklist
- [ ] Merge / quick / heap sort: complexity, stability, in-place or not
- [ ] Counting, radix, bucket sort and when they beat O(n log n)
- [ ] Custom comparators in your language
- [ ] Sorting + greedy combinations
- [ ] Merge-sort based inversion counting
- [ ] Quickselect for k-th element

## Online-assessment angle
MCQ favourites: which sort is stable, best/worst/average case, which is used by your language's library sort.

## Interview angle
'Sort it first' is a legitimate first move — but always state the added O(n log n) cost.
