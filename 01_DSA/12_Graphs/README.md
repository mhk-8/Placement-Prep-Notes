# Graphs

> Folder: `01_DSA/12_Graphs`

## Why this matters
Highest-difficulty band in OAs; grids are graphs in disguise.

## Must-know checklist
- [ ] Representations: adjacency list/matrix, edge list
- [ ] BFS/DFS, connected components, bipartite check
- [ ] Cycle detection in directed and undirected graphs
- [ ] Topological sort (Kahn + DFS)
- [ ] Dijkstra, Bellman-Ford, Floyd-Warshall — and when each applies
- [ ] MST: Kruskal, Prim
- [ ] Union-Find with path compression and union by rank
- [ ] Grid BFS, multi-source BFS, 0-1 BFS
- [ ] Bridges, articulation points, SCC (Tarjan/Kosaraju)

## Online-assessment angle
Multi-source BFS and topological sort (course-schedule family) are the most repeated OA graph problems.

## Interview angle
Always clarify: directed or not, weighted or not, negative weights, cycles allowed, connected?
