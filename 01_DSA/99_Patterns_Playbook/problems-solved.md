# Weak Pattern Ledger

> Not a problem log — `00_Start_Here/Trackers/problem-tracker.md` is that. This is the **pattern-level** view: which of the 22 do you not yet own?

## Ownership scale

- **0** — cannot recognise it in a problem statement
- **1** — recognise it, cannot write the template
- **2** — can write the template with notes
- **3** — can write the template cold
- **4** — can adapt it to a variant cold, under time
- **5** — can explain *why* it works and prove the invariant

**OA-ready = 3. Interview-ready = 5.**

## Rules

- Re-rate only at phase gates (W0, W4, W8, W10). Daily re-rating is procrastination.
- **Any pattern at ≤2 after Gate A is your next study session**, ahead of anything new.
- A pattern drops a level if you fail it in a timed mock, regardless of how well you know it in theory. Timed performance is the only rating that counts.
