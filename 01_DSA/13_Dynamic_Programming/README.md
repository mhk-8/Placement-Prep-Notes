# Dynamic Programming

> Folder: `01_DSA/13_Dynamic_Programming`

## Why this matters
The differentiator. Most candidates fail here, so strength here converts offers.

## Must-know checklist
- [ ] State definition, transition, base case, order of computation
- [ ] 1-D: climbing stairs, house robber, LIS (O(n log n) too)
- [ ] Knapsack family: 0/1, unbounded, subset-sum, partition
- [ ] 2-D grid DP: paths, min path sum, obstacles
- [ ] String DP: LCS, edit distance, palindromic substrings, regex match
- [ ] Interval DP: matrix chain, burst balloons
- [ ] Bitmask DP: TSP, assignment
- [ ] Digit DP basics
- [ ] Memoization vs tabulation vs space optimisation

## Online-assessment angle
Write the recurrence in a comment first. Under time pressure, memoized recursion is faster to get right than tabulation.

## Interview angle
Interviewers want the state definition in one sentence. Practise saying it before coding.
