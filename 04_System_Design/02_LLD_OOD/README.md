# Low-Level Design / OOD

> Folder: `04_System_Design/02_LLD_OOD`

## Why this matters
For freshers and 0-2 YOE roles this is the more likely design round: design classes for a concrete system in 45 minutes.

## Must-know checklist
- [ ] Requirements → entities → relationships → class diagram → interfaces → code skeleton
- [ ] SOLID applied, not recited
- [ ] Concurrency concerns in the design
- [ ] Classic problems: parking lot, elevator, BookMyShow, Splitwise, ATM, vending machine, chess/tic-tac-toe, rate limiter, logging framework, LRU cache, snake & ladder
- [ ] Extensibility: how does the design absorb a new requirement?

## Online-assessment angle
Some companies run a 'machine coding' OA: build a working CLI system in 90-120 minutes. Practise at least two under time.

## Interview angle
Write compiling, runnable code with clear class boundaries. Interviewers add a new requirement at minute 35 to test extensibility.
