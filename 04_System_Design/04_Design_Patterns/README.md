# Design Patterns

> Folder: `04_System_Design/04_Design_Patterns`

## Why this matters
Common in LLD rounds and in MCQ sections at service-based and product companies alike.

## Must-know checklist
- [ ] Creational: Singleton, Factory, Abstract Factory, Builder, Prototype
- [ ] Structural: Adapter, Decorator, Facade, Proxy, Composite
- [ ] Behavioural: Strategy, Observer, Command, State, Template Method, Iterator
- [ ] For each: problem it solves, UML sketch, a real usage you have seen, and its downside
- [ ] Anti-patterns: god object, singleton abuse

## Online-assessment angle
'Which pattern does X describe' is a standard MCQ.

## Interview angle
Name the pattern while designing — it signals maturity — but only where it genuinely fits.
