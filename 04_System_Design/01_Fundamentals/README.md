# Fundamentals & Building Blocks

> Folder: `04_System_Design/01_Fundamentals`

## Why this matters
The vocabulary. Without these you cannot participate in the conversation.

## Must-know checklist
- [ ] Scalability: vertical vs horizontal; stateless services
- [ ] Load balancing: L4 vs L7, algorithms, health checks
- [ ] Caching: cache-aside, write-through, write-back; eviction; CDN; cache invalidation
- [ ] Databases: SQL vs NoSQL, sharding, replication (leader-follower, multi-leader), partitioning strategies
- [ ] CAP and PACELC; eventual vs strong consistency
- [ ] Message queues and pub/sub: Kafka, SQS; at-least-once vs exactly-once
- [ ] Rate limiting algorithms: token bucket, leaky bucket, sliding window
- [ ] Consistent hashing
- [ ] Bloom filters
- [ ] Microservices vs monolith; API gateway
- [ ] Observability: metrics, logs, traces, SLA/SLO
- [ ] Back-of-envelope estimation numbers (latency table)

## Online-assessment angle
Occasionally MCQ'd as 'which of these ensures X'.

## Interview angle
Use the right term precisely; vague usage of 'consistency' or 'sharding' is penalised.
