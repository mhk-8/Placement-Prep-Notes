# 04 — System Design

> Folder: `04_System_Design`

## Why this matters
Appears from the second technical round onward, and increasingly even for fresher SDE roles at top MNCs in a lighter form (LLD / OOD). It is the round where communication is graded as heavily as knowledge.

## Must-know checklist
- [ ] Have a repeatable framework: requirements → estimates → API → data model → high-level → deep dive → bottlenecks
- [ ] Back-of-envelope numbers: QPS, storage, bandwidth
- [ ] Know the standard building blocks and their trade-offs
- [ ] Be able to design 2-3 classic systems end to end without hesitation
- [ ] For freshers: LLD is more likely than HLD — prioritise accordingly

## Online-assessment angle
Rare in OAs; occasionally a multiple-choice 'which architecture fits' section.

## Interview angle
Drive the conversation. Ask clarifying questions for the first 5 minutes; never start drawing immediately.
