# Technical Round Prep

> Folder: `07_Interviews/01_Technical_Round_Prep`

## Why this matters
How to behave in the round, as distinct from what to know.

## Must-know checklist
- [ ] The 6-step protocol: clarify → examples → brute force → optimise → code → test & complexity
- [ ] Clarifying questions worth asking for any problem (input size, duplicates, negatives, empty, sorted?)
- [ ] How to use hints without looking dependent
- [ ] What to do when you are stuck: state your blocker aloud
- [ ] Dry-running your code on an example before saying 'done'
- [ ] Whiteboard/shared-editor hygiene: naming, spacing, no shortcuts
- [ ] Mock interview log: date, partner, problem, feedback, action

## Online-assessment angle
Not applicable.

## Interview angle
Record yourself solving one problem aloud. It is uncomfortable and it is the fastest improvement available.
