# Resume & Portfolio

> Folder: `07_Interviews/03_Resume_and_Portfolio`

## Why this matters
The resume determines which questions you get asked. Every line is an invitation.

## Must-know checklist
- [ ] One page, reverse chronological, quantified bullets (action → method → measurable result)
- [ ] No skill listed that you cannot answer 3 questions on
- [ ] ATS-friendly formatting; no tables or images in the PDF
- [ ] GitHub tidy: READMEs, pinned repos, no dead projects on top
- [ ] LinkedIn consistent with the resume
- [ ] Versions tailored to SDE vs AI/ML roles
- [ ] Keep `resume-v<n>.pdf` versions with a changelog

## Online-assessment angle
Some OAs are preceded by a resume shortlist — keywords matter.

## Interview angle
Expect 'walk me through your resume' as the opener in nearly every round.
