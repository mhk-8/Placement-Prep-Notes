# Questions To Ask Them

> Folder: `07_Interviews/05_Questions_To_Ask`

## Why this matters
Signals seriousness and gives you information you actually need to choose.

## Must-know checklist
- [ ] About the role: day-to-day, first 6 months, team size and structure
- [ ] About engineering: code review, testing, on-call, tech debt, release cadence
- [ ] About growth: mentorship, mobility, learning budget, promotion cycle
- [ ] About the team's current hardest problem
- [ ] Never in round 1: salary, leave policy, work hours

## Online-assessment angle
Not applicable.

## Interview angle
Keep 5 ready, ask 2-3, and adapt them to what the interviewer actually said.
