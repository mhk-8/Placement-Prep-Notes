# 07 — Interviews

> Folder: `07_Interviews`

## Why this matters
The OA gets you the interview; the interview gets you the offer. Technical correctness is necessary, not sufficient — clarity, structure and honesty are graded throughout.

## Must-know checklist
- [ ] Have a rehearsed 90-second introduction
- [ ] Be able to explain every line of your resume
- [ ] Practise thinking aloud — silent problem-solving reads as being stuck
- [ ] Prepare 3-4 STAR stories that can be reshaped for most behavioural questions
- [ ] Always have 2-3 questions ready for the interviewer
- [ ] Debrief within 2 hours of every interview, while memory is fresh
